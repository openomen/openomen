OpenOMEN - How to Build and Release Binary

This document explains how to build the OpenOMEN CLI into a standalone Linux binary using a Python virtual environment and PyInstaller.

------------------------------------------------------------
1. REQUIREMENTS
------------------------------------------------------------

Make sure you have:

- Python 3 installed
- venv module available

Install venv if needed.

------------------------------------------------------------
2. CREATE VIRTUAL ENVIRONMENT
------------------------------------------------------------

From the project root directory:

    python3 -m venv .venv

Activate it:

    source .venv/bin/activate

You should now see (.venv) in your terminal.

------------------------------------------------------------
3. INSTALL DEPENDENCIES
------------------------------------------------------------

Upgrade pip:

    python -m pip install --upgrade pip

Install PyInstaller:

    pip install pyinstaller

------------------------------------------------------------
4. BUILD BINARY
------------------------------------------------------------

From the project root (with venv activated):

    pyinstaller openomen.spec

The spec builds a single-file binary from the `openomen` entry script and
pulls in the `openomen` package from src/ (pathex=['src']). The equivalent
one-off command is:

    pyinstaller --onefile --name openomen --paths src openomen

GUI binary (gui branch, read-only preview for now):

    pip install PySide6
    pyinstaller openomen-gui.spec     # -> dist/openomen-gui (~45 MB)

Running the GUI from source on NixOS (pip's Qt wheels need libraries NixOS
doesn't provide, so use the dev shell with PySide6 from nixpkgs):

    nix-shell --run ./openomen-gui

Code layout:

    openomen               entry script (also runnable directly from a checkout)
    src/openomen/          the package; VERSION lives in src/openomen/__init__.py
    src/openomen/core/     hardware access, returns data (shared with the GUI)
    src/openomen/cli.py    argument parsing and text / --json output

------------------------------------------------------------
5. OUTPUT
------------------------------------------------------------

The compiled binary will be located at:

    dist/openomen
    dist/openomen-gui

This is the standalone executable for Linux.

------------------------------------------------------------
6. PUBLISH ON GITHUB (what `openomen update` expects)
------------------------------------------------------------

- Tag the release CLI_X.Y.Z (or vX.Y.Z / X.Y.Z), matching VERSION in src/openomen/__init__.py.
  The updater refuses a binary whose `--version` differs from the tag.
- Upload the binary as an asset named exactly: openomen
- Don't mark it as a pre-release; pre-releases and drafts are skipped.
- Checksums: GitHub publishes a SHA-256 digest for every uploaded asset, and the
  updater verifies it automatically. Optionally also upload `openomen.sha256`
  (output of `sha256sum dist/openomen`), which `update -f` uses.

------------------------------------------------------------
7. NOTES
------------------------------------------------------------

- The binary is Linux-specific (not cross-platform)
- Root privileges (sudo) are required for hardware control
- Tested primarily on HP OMEN / Victus laptops
